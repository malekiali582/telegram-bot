# اجرای پنل مدیریت روی سیستم خودتان (حالت توسعهٔ پنل)

این راهنما برای دیدن و آزمودن پنل مدیریت روی کامپیوتر خودتان است: بدون Docker، بدون سرور و **بدون تلگرام**.

```
npm run dev:panel
```

بعد مرورگر را روی `http://localhost:5173` باز کنید.

## چه چیزی اجرا می‌شود و چه چیزی نه

- **فقط API و پنل.** ربات، worker و ارسال پیام اجرا نمی‌شوند.
- **بدون تلگرام:**
  - فایل `.env` اصلاً خوانده نمی‌شود، پس توکن ربات وارد این برنامه نمی‌شود؛
  - هر اتصال از این برنامه به تلگرام (نام دامنه یا IPهای تلگرام) پیش از ارسال حتی یک بایت مسدود می‌شود و در ترمینال پیام «⛔» می‌آید؛
  - این حالت امن است حتی وقتی ربات واقعی با همان توکن روی سیستم دیگری روشن است.
- **دیتابیس جدا:**
  - PostgreSQL محلی در پوشهٔ `.lulu-panel-dev/` روی پورت ۵۴۳۳۰؛
  - به `.lulu-dev/` (دیتابیس `npm run dev` ربات) دست نمی‌زند؛
  - این پوشه در git نیست.

## دادهٔ نمونه

بار اول (حدود یک دقیقه) دادهٔ نمونه با **همان سرویس‌های واقعی بازی** ساخته می‌شود؛ پس همهٔ عددها از تراکنش‌های واقعی ledger می‌آیند:

- ۶۰ بازیکن و ۸ گروه، از هر دو پلتفرم تلگرام و روبیکا؛
- ۴۵ روز تاریخچه: لولو، شکار، غذا، ارتقای سطح، ابزار، گنجینه و سود، قبرستان، اهدای خون، روح‌ها و استریک‌ها؛
- یک بازیکن مسدود، یک گروه که ربات را حذف کرده، یک گروه مهاجرت‌کرده به supergroup؛
- بسته‌های روح گذشته، فعال و آینده؛
- یک پیام ناموفق در صف ارسال و یک اجرای ناموفق در کارهای زمان‌بندی‌شده.

اسم همهٔ بازیکن‌ها و گروه‌ها با «[نمونه]» شروع می‌شود و در دیتابیس هم علامت نمونه (`is_sample`) دارند. در بالای پنل نوار «حالت توسعه» دیده می‌شود.

دادهٔ نمونه هرگز در production ساخته نمی‌شود، و روی دیتابیسی که حتی یک بازیکن یا گروه واقعی دارد هم ساخته نمی‌شود.

برای دادهٔ نمونهٔ تازه: پنل را ببندید و پوشهٔ `.lulu-panel-dev/` را پاک کنید.

## ورود

- بار اول یک حساب مالک با نام کاربری `owner` ساخته می‌شود و **رمزش یک بار در ترمینال چاپ می‌شود**.
- این حساب فقط در همین دیتابیس محلی وجود دارد.
- اگر رمز را ندارید:

  ```
  npm run dev:panel -- --new-password
  ```

  رمز تازه چاپ می‌شود و نشست‌های قبلی بسته می‌شوند.

## پورت‌ها

اگر پورتی گرفته بود، آن را در **ترمینال** عوض کنید (نه در `.env`):

| متغیر                | پیش‌فرض | کاربرد         |
| -------------------- | ------- | -------------- |
| `PANEL_DEV_DB_PORT`  | ۵۴۳۳۰   | PostgreSQL پنل |
| `PANEL_DEV_API_PORT` | ۳۱۰۰    | API            |
| `PANEL_DEV_PORT`     | ۵۱۷۳    | پنل در مرورگر  |

مثال در PowerShell:

```
$env:PANEL_DEV_PORT=5180; npm run dev:panel
```

## خاموش کردن

`Ctrl + C` در همان ترمینال. PostgreSQL پنل هم مرتب خاموش می‌شود.

# حساب مالک روی سرور (production)

روی سرور حساب پیش‌فرض یا رمز عمومی وجود ندارد. اولین حساب مالک این‌طور ساخته می‌شود:

1. در `.env` سرور این دو را پر کنید (رمز دست‌کم ۱۲ نویسه):

   ```
   ADMIN_BOOTSTRAP_USERNAME=...
   ADMIN_BOOTSTRAP_PASSWORD=...
   ```

2. اجرا کنید:

   ```
   npm run admin:bootstrap
   ```

3. این دو خط را از `.env` پاک کنید.

این دستور فقط وقتی حساب می‌سازد که هیچ مدیری وجود نداشته باشد؛ اجرای دوباره‌اش چیزی اضافه نمی‌کند. مدیران بعدی از صفحهٔ «مدیران» در پنل اضافه می‌شوند (بخش ۸.۸).
