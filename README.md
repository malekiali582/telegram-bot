# لولو

بازی گروهی «لولو» برای تلگرام، با پنل مدیریت فارسی.

| بخش    | چه می‌کند                                                           |
| ------ | ------------------------------------------------------------------- |
| ربات   | پیام‌ها و دکمه‌های تلگرام را از webhook می‌گیرد                     |
| worker | پیام‌ها را به تلگرام می‌فرستد و کارهای زمان‌بندی‌شده را اجرا می‌کند |
| API    | پنل مدیریت و API آن                                                 |

همه روی PostgreSQL کار می‌کنند.

## مستندات

| می‌خواهم…                                          | سند                                            |
| -------------------------------------------------- | ---------------------------------------------- |
| ربات و پنل را روی سرور راه بیندازم (از صفر)        | [`docs/server-setup.md`](docs/server-setup.md) |
| اجرای سرور: سرویس‌ها، HTTPS، به‌روزرسانی، عیب‌یابی | [`docs/operations.md`](docs/operations.md)     |
| با پنل کار کنم و وارد شوم                          | [`docs/panel.md`](docs/panel.md)               |
| بکاپ بگیرم و بازگردانی کنم                         | [`docs/backup.md`](docs/backup.md)             |
| ربات را روی کامپیوتر خودم امتحان کنم               | [`docs/dev-mode.md`](docs/dev-mode.md)         |
| پنل را بدون تلگرام و با دادهٔ نمونه ببینم          | [`docs/panel-dev.md`](docs/panel-dev.md)       |
| قاعده‌ها و تصمیم‌های بازی را ببینم                 | [`docs/assumptions.md`](docs/assumptions.md)   |

## دستورهای توسعه

```
npm ci                       # نصب
npm run dev                  # ربات روی کامپیوتر خودتان (polling)
npm run dev:panel            # پنل با دادهٔ نمونه، بدون تلگرام
npm run check                # format، typecheck، lint و همهٔ تست‌ها (PGlite و PostgreSQL واقعی)
npm run check:panel-browser  # سناریوی کامل پنل در مرورگر، موبایل و دسکتاپ
npm run build                # ساخت برای سرور
```
